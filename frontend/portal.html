Your wallet is your OliveChain account.

Create a wallet without an administrator or connect the wallet already stored in this browser. Organizational roles remain controlled by Fabric MSPs.

Secure browser context required. Wallet signing uses Web Crypto. Open OliveChain through HTTPS or localhost; plain LAN HTTP cannot safely create or use a browser wallet.

Create wallet

No password is created or stored. A P-256 signing key is generated in this browser and the public wallet identity is registered on Fabric.

Specialized roles such as Mill, Laboratory, Bottler and Processor are not available through public sign-up.
Private key: stays inside this browser's IndexedDB. FastAPI and Fabric receive only the public key and wallet address.

Connect wallet

OliveChain sends a one-time challenge. Your browser signs it locally and the server verifies the signature against the public key registered on Fabric.
